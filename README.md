# Форма — студия SVG-композиций

Работающий локальный веб-сервис для сборки иллюстраций из существующих SVG. Интерфейс на русском языке, frontend на React и TypeScript, backend на **Python / FastAPI**.

**Оригинальные SVG из Figma в проект не включены.** Файл по предоставленной ссылке не удалось прочитать без подключения Figma. Начальная библиотека содержит только явно обозначенные технические демо-фигуры. Это не восстановленные иллюстрации из задания. Для визуального соответствия загрузите экспортированные из Figma SVG.

## Возможности

- Подбор объектов по теме или ручной выбор, 3 и 6 вариантов, шесть стратегий композиции.
- Генерация без интернета и API-ключей после установки зависимостей.
- Импорт нескольких SVG, поиск, категории, теги, объединение исходных версий S/L и main/background.
- Нативный SVG-редактор: выделение, drag-and-drop, пропорциональное масштабирование за углы, поворот за круглую ручку; Shift округляет поворот до 15°.
- Дублирование, удаление, видимость, порядок слоёв, параметры объекта, направляющие и масштаб вида.
- Undo/redo с историей до 50 операций; перетаскивание считается одной операцией.
- Lavender, Peach, Mint; семантическая карта цветов вместо замены строк.
- Square 1080×1080, Landscape 1600×900, Portrait 1080×1350, Story 1080×1920.
- Экспорт самостоятельного SVG, JSON с исходниками и параметрами, загрузка JSON.
- Автосохранение в IndexedDB; библиотека и проекты на Python-сервере в SQLite.

## Технологии

React 19, TypeScript, Vite, Tailwind CSS 4, Zustand, Lucide React, DOMParser/XMLSerializer, IndexedDB. Python 3.12+, FastAPI, Pydantic, SQLite, defusedxml, Uvicorn. Тесты: Vitest, pytest, Playwright. Все шрифты системные; внешние CDN и картинки для работы приложения не нужны.

## Установка

Нужны Node.js 22.12+ (проверено на Node.js 24) и Python 3.12+.

Windows PowerShell:

```powershell
cd D:\projects\test_stasya
npm.cmd ci
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.lock
```

Если Python запускается через launcher, замените `python -m venv .venv` на `py -3 -m venv .venv`. Активация virtualenv не требуется. Использование `npm.cmd` обходит блокировку `npm.ps1` политикой PowerShell.

Linux / macOS:

```bash
npm ci
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.lock
```

## Запуск

**Готовая сборка и Python-сервер — один адрес:**

```powershell
npm.cmd run build
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Откройте **http://127.0.0.1:8000**. Бэкенд раздаёт `dist/`; сборка должна существовать до запуска Uvicorn. API-документация: http://127.0.0.1:8000/docs.

**Разработка — два терминала:**

```powershell
# Терминал 1
npm.cmd run backend
# Терминал 2
npm.cmd run dev
```

Frontend: http://127.0.0.1:5173. Vite проксирует `/api` на порт 8000. Для Linux запускайте `.venv/bin/python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000` и `npm run dev`.

Остановка — Ctrl+C. Если сервер недоступен, генерация и редактор продолжают работать в браузере; «Сохранить» скачивает резервный JSON. Для первоначальной загрузки страницы нужен запущенный HTTP-сервер. Service worker и установка PWA не предусмотрены.

## Переменные окружения

Смотрите [.env.example](.env.example). `FORMA_DATA_DIR` задаёт директорию SQLite, по умолчанию `.data` относительно рабочей папки. Например, `$env:FORMA_DATA_DIR='D:\projects\test_stasya\.data'`. Файл `.env` автоматически не загружается: переменные задаются в оболочке запуска. Внешний AI не подключён, ключи не требуются и в браузер не передаются.

## Как загрузить библиотеку SVG

1. Экспортируйте отдельные компоненты из Figma как SVG, сохранив векторные пути. Растровые вставки не поддерживаются.
2. Нажмите «Импорт SVG» в левой панели. Можно выбрать несколько файлов, до 2 МБ каждый.
3. Кнопка параметров рядом с категориями задаёт роль и размер импортируемой версии, а также теги.
4. Для объединения версий используйте имена `книга__main__S.svg`, `книга__main__L.svg`, `книга__background__S.svg`, `книга__background__L.svg`. Базовое имя становится ключом объекта; повторный импорт одинаковой версии заменяет её. Роль по умолчанию main, размер L.
5. Настройки внизу карточки позволяют добавить теги и назначить исходным цветам семантические роли.
6. Нажмите на карточку для выбора в генераторе, на «+» — для добавления на текущий холст.

Импорт допускает безопасное подмножество SVG: пути, фигуры, группы, текст, gradients, masks, clipPaths, patterns, локальные `use` и стандартные фильтры теней/размытия без `feImage`. Скрипты, обработчики событий, CSS-стили с неподдерживаемыми свойствами, foreignObject, анимация, внешние ссылки и raster image отклоняются. Неподдерживаемые файлы дают понятную ошибку, а не частично испорченную графику. Для текста, который должен выглядеть одинаково на всех машинах, переведите шрифты в кривые в Figma перед экспортом.

## Генератор композиций

`src/services/CompositionEngine.ts` не зависит от React. Получает библиотеку, тему/ID выбранных объектов, формат, палитру, seed, плотность декора и размер исходника. Возвращает типизированный JSON.

Шесть стратегий: центральная, диагональная, асимметричная, треугольная, главный объект с второстепенными, декоративное окружение. Для каждого варианта создаются 22 кандидата с заданными опорными точками, иерархией и контролируемыми отклонениями. Выбирается кандидат с лучшей оценкой перекрытий, баланса, заполнения, расстояний и границ. Seed воспроизводит результат. Фон добавляется только при наличии исходного фонового варианта.

Все координаты нормализованы; масштаб задаёт длину большей стороны относительно меньшей стороны холста. Один коэффициент применяется к обеим осям. Размеры повёрнутых bounding boxes учитываются при размещении и адаптации формата. Одновременно можно генерировать до 24 выбранных объектов.

## Анализ текста

`SemanticMatcher` использует русские/английские основы слов, теги, ключевые слова и словарь связанных понятий: обучение, творчество, команда, планирование. Прямое совпадение имеет больший вес, чем связь по теме. Возвращает существующие objectId, веса, объяснение и стратегию. При отсутствии совпадений показывает сообщение и предлагает ручной выбор. Названия отсутствующих оригинальных компонентов не подменяются иллюстрациями.

## Хранение SVG и проектов

Библиотека `Asset` хранится отдельно от массива экземпляров `ElementInstance`. У экземпляра только objectId, роль, размер, координаты и трансформации. Изменения экземпляров не меняют SVG-источник. Параметры и библиотека автоматически сохраняются в IndexedDB. JSON-проект переносит библиотеку целиком и не зависит от локальных путей.

FastAPI повторно проверяет каждый SVG и все ссылки проекта через Pydantic/defusedxml, пересчитывает viewBox и aspect ratio. SQLite хранит JSON исходников и проектов с транзакциями. Сохранение того же ID композиции обновляет запись. `GET /api/projects` показывает последние 100 проектов. Импортируемая библиотека записывается в API, открытие проекта восстанавливает библиотеку из его JSON. Непрерывная синхронизация между устройствами не реализована.

## Палитры и экспорт

Палитры централизованы в `src/data/palettes.ts`. Основные, фоновые, акцентные цвета, тени и контуры разделены. `PaletteService` обходит XML-узлы и атрибуты цвета, применяя явную карту. У неизвестных цветов сохраняется оригинал и показывается предупреждение. Это осознанное исключение для импортированных файлов без настроенной карты, чтобы не портить исходную графику.

`SvgExportService` создаёт новый SVG с точными размерами и viewBox. Каждый исходник встраивается в SVG-узел с пропорциональным размером; размещение и поворот задаются группой. Экземпляры сортируются по zIndex; скрытые исключаются. Все id и локальные ссылки на gradients, masks, clipPaths и use получают уникальный префикс экземпляра. Экспорт не содержит интерфейсных рамок, локальных файлов, raster image, base64-картинок или внешних ресурсов.

## Примеры

- «Обучение и развитие»: демо-карточки и арка подбираются по тегам. С оригинальной библиотекой будут выбраны книга/блокнот/карандаш, если им назначены соответствующие теги.
- «Креативность и новые идеи»: подбор по тегам творчества, три или шесть разных композиций.
- Ручной выбор: отметьте три карточки и откройте «Создать композицию» → «Из выбранных элементов».
- Меняйте Square/Landscape/Portrait/Story и Lavender/Peach/Mint в правой панели.

## Проверки

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run test:backend
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

Playwright автоматически запускает frontend и Python API на портах 5173/8000. Он проверяет генерацию, редактирование/undo, смену палитры/формата, экспорт, импорт, сохранение/восстановление через API и мобильную ширину. E2E-сохранения попадают в локальную `.data`; unit/API-тесты используют изолированное временное хранилище.

Проверено в этом окружении: production-сборка TypeScript/Vite, **35 тестов Vitest, 22 теста pytest и 3 сценария Playwright**. Дополнительно проверена раздача готовой сборки Python-сервером и отображение на ширинах 1440, 1280 и 390 px; ошибок JavaScript и горизонтального переполнения нет. Скриншоты находятся в `.artifacts/studio-desktop.png`, `.artifacts/studio-compact.png`, `.artifacts/studio-mobile.png`.

Для повторной визуальной проверки запустите готовую сборку на порту 8000 и выполните `node scripts/capture-preview.mjs`. Если Chromium расположен вне стандартного кэша Playwright, задайте путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

## Ограничения

Оригинальные SVG не получены из Figma; точное совпадение иллюстраций возможно после импорта. Внешний AI — опциональная часть задания — не подключён. Сервис предназначен для локального запуска на 127.0.0.1: нет пользовательских аккаунтов и публичного многопользовательского режима. Python backend не публиковался в Sites: его среда Cloudflare Workers не запускает этот FastAPI-сервер. Для внешнего размещения необходим сервер с Python и постоянным диском SQLite.
